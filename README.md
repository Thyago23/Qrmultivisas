# Multivisa · Links

Página única con los links a las redes de Multivisa (TikTok, Instagram y Facebook). Sitio estático, sin build.

## Desplegar en Vercel

1. En [vercel.com/new](https://vercel.com/new) importar el repo `Thyago23/Qrmultivisas`.
2. Framework Preset: **Other**. Dejar Build Command y Output Directory vacíos.
3. Deploy. Cada push a `main` vuelve a desplegar.

## Probar local

```bash
python3 -m http.server 8000
```

y abrir http://localhost:8000
